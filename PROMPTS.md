# Example Copilot Prompts

## Planning

> Read AGENTS.md and the relevant architecture/testing docs. Plan Exercise 2 from TASKS.md. Do not modify code yet. Show affected files, tests, and risks.

## Implementation

> Implement Exercise 2 from TASKS.md following the approved plan and repository instructions. Run npm run verify before finishing.

## Review

> Review all uncommitted changes against AGENTS.md. Focus on correctness, architecture, security, tests, and unintended behavior. Give findings before suggestions.

## Bug investigation

> Investigate why this failing test occurs. Reproduce the failure, identify the root cause, and propose the smallest safe fix before editing code.

## Refactoring

> Find duplication in the item use cases, but do not refactor yet. Explain whether removing it would improve the design enough to justify the change.
